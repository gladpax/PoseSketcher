# PoseSketcher - 项目总体功能说明

## 1. 项目愿景与定位
PoseSketcher 是一个基于 Web 的轻量级交互式人体姿态起稿系统。
其核心愿景是让用户可以通过极简的鼠标或触控笔滑动操作——遵循“一笔画出躯干主轴，四笔引出对应四肢”的交互直觉，快速在画布上生成具各有关节结构和基础物理透视的人体 2D 骨骼与胶囊体截面。生成后，用户可以通过随意拖曳关节点对人体姿态进行重新二次微调构建，极为适合绘画前期草图的体块打型、速写起稿以及动作设计灵感的捕捉。项目愿景是构建一个可以像书写汉字一样的方法，在2D平面轻松快速描绘人物的各种动作，各种角度的动作,并且很容易编辑,形态逼真,可自定义人物身体形态比例,用于图像制作领域

## 2. 核心系统与交互机制
- **极简生成机制 (Stroke-based Skeleton Hooking)**：
  - **躯干主轴产生**：用户在画布上划出一根长线（超过20px），系统通过对该线段取样长度，建立相对标尺（`scale`），同时分配并推算出头部、颈部、胸前腰部以及盆骨点。
  - **四肢挂载连接**：用户将鼠标悬停在刚生成的肩膀段或胯部段，按下鼠标划出一条新线。该线即可被自动判定为手臂或腿部，同时通过系统算出的 `L` (长度) 自动打出对应肘部、膝盖、手腕、脚踝及拇指、脚尖等点位。
- **空间投影与视图控制**：
  - **正常正面模式 (鼠标左键滑动主轴)**：系统生成拥有正常横向对称分布的肩宽与骨盆宽度的人体结构。
  - **侧面板绘制模式 (鼠标右键滑动主轴)**：系统标记人物 `isSideView: true`，极大限度收缩两肩、两臀间距，提供模拟侧身透视以及同侧手部朝向处理。
- **物理联动编辑约束**：
  - 通过 `CharacterRenderer` 将骨骼呈现为 UI 可拖拽热区。
  - 核心包含了一个树状关联驱动系统（存放在 `utils.ts` 的 `updateCharacter` 里）。当拉动父节点如“颈骨”时，会带动头骨平移；当拖拉腰部时会带动双腿进行平移，使得骨骼在发生编辑时能够较好地维系“不脱节、不离体”的结构特点。 

## 3. 核心技术栈 (Tech Stack)
项目采用纯前端、轻量、无需独立配置底层 Canvas 开销引擎的实现方式：
- **核心框架**：React 18 + TypeScript (保障数据解构、状态强类型限制以及核心函数的纯净易测试性)
- **图形渲染层**：SVG (Scalable Vector Graphics) 
  - 所有可视化的身体部件（线段、胶囊肌肉层、关节圆点）均由 `<path>`, `<circle>`, `<line>` 以及 `<g>` 标签直接构筑。
  - **性能层面**：通过 `React.memo` 作为渲染性能屏障，严格剥离只允许拖拽行为中的变更进行局部刷新。
- **构建环境方案**：Vite 工具链（提供极速 HMR 本地热更新和打包剔除）
- **现代化视觉控制**：Tailwind CSS (应用在所有的 UI 面板与绝对定位工具栏)，搭配 Lucide-React 为整个工具提供专业感与功能可读性。

## 4. 关键架构目录映射
- [src/types.ts](src/types.ts) : 贯穿整个业务的数据类型文件（定义 `Character` 模型、骨盆臂腿数据层级结构）。
- [src/App.tsx](src/App.tsx) : 中心大脑。负责事件捕获 (`pointerDown`, `Move`, `Up`)，负责 `State` (人物集合, 撤销堆栈, 拖放缓存池) 的流转更迭，以及页面悬浮 UI 按钮栏的装载。
- [src/utils.ts](src/utils.ts) : 纯数学函数逻辑中枢。系统里最复杂的工作（肢距测算、点位映射、连结热区判定、关节联协移位、左右侧向生成等）都被拆解在这里形成无副作用的纯函数输出。
- [src/components/CharacterRenderer.tsx](src/components/CharacterRenderer.tsx) : 负责把抽象层 `char` 数据进行最终结构翻译，将它转化成基于数学圆及带有动态胶囊体粗细系数 (`Capsule`) 显示的可视化 HTML/SVG DOM 树。
